# Duolingo do Banco de Dados

Esse projeto é um web app estilo Duolingo feito para ajudar a galera da faculdade a estudar Banco de Dados sem morrer de tédio. A ideia é aprender a matéria jogando, fazendo lições curtas e acumulando pontos.

## O que o app faz

* **Trilhas de aprendizado:** A matéria é dividida em módulos, do básico até os tópicos mais avançados.
* **Lições rápidas:** Questões de múltipla escolha, preenchimento de lacunas e desafios de código baseados na matéria de banco de dados.
* **Sistema de ofensiva (Streak):** Mantém o controle de quantos dias seguidos você estudou para te ajudar a criar o hábito (salvo no navegador).
* **XP e Ranking:** Cada lição completada te dá pontos de experiência para você acompanhar sua evolução.

## Módulos de estudo inclusos

* **Conceitos Básicos:** O que é um SGBD, dados vs informação e arquitetura de banco de dados.
* **Modelagem de Dados:** Entidades, atributos, relacionamentos e como montar um MER/DER sem errar.
* **Modelo Relacional:** Passando o modelo conceitual para o lógico, chaves primárias e chaves estrangeiras.
* **Normalização:** Regras para evitar redundância (1FN, 2FN, 3FN e até a Forma Normal de Boyce-Codd).
* **Linguagem SQL:** Comandos DDL (Create, Alter, Drop) e DML (Select, Insert, Update, Delete) do básico aos JOINS avançados.

## Tecnologias usadas

* **Estrutura:** HTML5
* **Estilização:** CSS3
* **Comportamento e Lógica:** JavaScript (Vanilla JS)

## Como rodar o projeto na sua máquina

Como o projeto foi feito com tecnologias web nativas, rodar ele é bem direto e não precisa instalar nenhuma dependência do Node ou pacotes externos.

1. Clone este repositório:
```bash
git clone https://github.com
```

2. Entre na pasta do projeto:
```bash
cd seu-repositorio
```

3. Para abrir o app, você tem duas opções bem fáceis:
   * **Opção 1:** Basta dar um duplo clique no arquivo `index.html` para abrir ele direto no seu navegador padrão.
   * **Opção 2 (Recomendada):** Se você usa o VS Code, instale a extensão **Live Server**, clique com o botão direito no `index.html` e escolha "Open with Live Server" para rodar o app com recarregamento automático.
